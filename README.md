# Vegreville Bowling Hub

Build a complete, polished, fully responsive Vegreville Bowling Lanes website and web application for a real 5-pin bowling centre in Vegreville, Alberta. Start with the complete public-facing structure and design, then implement the backend/database architecture and dashboards for booking requests, leagues, player stats/automatic average recalculation, score entry, and role-based admin/player access. Follow all requirements in the user’s detailed prompt, including every named page, 5-pin accuracy, accessible mobile-first layouts, realistic content/images, reusable components, bookings/events/menu/party/rental models, and a professional neon family-entertainment visual style.
